Sheet layout

Auto-detect stickers

Finds each separate shape on the sheet and saves its bounding box as a region. Works with sheets of any layout.

Threshold: the alpha (or the difference from the corner color) a pixel needs to count as part of a sticker. Merge gap: shapes this many pixels apart or closer become one region. Raise it for stickers made of loose parts, like separate letters. Min size ignores specks smaller than this. Padding grows each box outward.

Overlay UVs

Hammer's default values on this face

Hammer sets an overlay's U Start/End and V Start/End to 0 and 1 in an order that depends on which way the face points. Place the overlay first, read its U Start and V Start, and pick the matching option. The crop then keeps that direction, so the sticker isn't mirrored.
